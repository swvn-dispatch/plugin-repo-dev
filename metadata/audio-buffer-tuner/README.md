# Audio Buffer Tuner

**Version:** `0.4.2` | **Author:** CtznSniiips | **Last Updated:** Nov 17 2026, 17:06 UTC

Speeds up channel startup for low-bitrate (usually audio only) streams by lowering the TS-proxy prebuffer for chosen Channel Groups.
